# F-001 · Ejemplo de nota de historia

**Qué pasó.** Un endpoint devolvía el historial de un recurso sin comprobar que quien lo pedía tuviera acceso a ese recurso; la pantalla lo escondía, la API no.

**Medición.** Reproducido con un segundo usuario sin acceso: 200 con datos.

**Decisión.** Todo endpoint que devuelve datos de un recurso valida el acceso a ESE recurso. Regla en `.claude/rules/permisos.md`. Prueba que falla con el código anterior: `auth.spec.ts`.
